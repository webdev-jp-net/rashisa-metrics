# UI/UX表記規約

## 概要

本ドキュメントは、UIの文言（ボタン・リンク・メッセージ）の書き方を統一するための規約。ドメイン用語の選び方は[開発用ネーミング辞書](./dictionary.md)が正本で、本ドキュメントは対象としない。

## 全角と半角の境目

最優先で守るルール。本ドキュメント・仕様書・コード内のユーザー向け文言・コミットメッセージ等、本プロジェクトに関わるすべての日本語テキストに適用される。

`textlint-rule-preset-jtf-style`（`.textlintrc.json`）にしたがう。有効なルールは以下の2つのみで、他のJTFルールはすべて無効。

- `3.1.1.全角文字と半角文字の間`：全角文字と半角文字の境目にスペースを入れない（例：`microCMS管理画面`、`URLパラメータ`）
- `2.1.6.カタカナの長音`：外来語の長音符号「ー」を省略しない（例：`サーバー`、`ユーザー`）

## 文体

- **敬語レベル**：丁寧語（です・ます調）を基本とする（例：「閲覧できます」「ありません」）
- **記号**：句読点は「、」「。」、カッコは全角「（）」（例：`（暫定）`、`（形態素1,000あたり）`）

## CTA・アクションの文言

| 推奨表記       | 避けるべき表記 | 使用場面                      |
| -------------- | -------------- | ----------------------------- |
| レポートをみる | レポート       | `IntroSection`の`.hint`リンク |
| ログインする   | ログイン       | ログイン促し画面のボタン      |

## 数値表記

書式の正本は`src/app/_parts/format.ts`。

| 種別   | 推奨表記                | 例        |
| ------ | ----------------------- | --------- |
| 百分率 | 小数点3桁固定           | `15.549%` |
| 差分   | 符号付き（`+`も付ける） | `+0.42`   |
| 文字数 | 3桁区切り               | `1,234`   |

## メッセージ文言の型

非許可・未ログイン時に画面全体を差し替えて表示する状態説明文（`LoginPrompt`、文言の正本は`useLoginPrompt.ts`）の型。

- **推奨**：「〜です。〜すると〜できます。」のような、現在の状態と次の行動を丁寧語で述べる文
- **例**：「このレポートは限定公開です。権限のあるアカウントでログインすると閲覧できます。」

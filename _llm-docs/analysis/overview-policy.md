# 判定規則

全体と個別スコープ（全体1行＋`<editedSource>/index.json`のスコープの件数）を、お手本媒体とだけ比較し、スコープ間の順位付けはしない。ルールの版は`overview-3`。実装は`src/lib/policy/`に置き、正本は同モジュールが持つ`POLICY`定数（`version: "overview-3"`）。閾値は著者同一性の実証済み境界ではなく、編集候補を絞るための暫定ルールであり、変更する場合は`POLICY`のバージョンも変更する。

## 27項目の構成

比較列は28列生成し、うち1列（敬語合計）を強調・件数から除外して27項目を数える。

| 群     | 項目                                                                           | 件数        |
| ------ | ------------------------------------------------------------------------------ | ----------- |
| LSM    | 平均                                                                           | 1           |
| 文法語 | 格助詞・係助詞・接続助詞・終助詞・助動詞・接続詞・代名詞・副詞・否定・数量詞   | 10          |
| 文末   | です・ます／体言止め等／文末なし／終助詞止め／記号止め／だ・である／絵文字止め | 7           |
| 丁寧度 | 丁寧語・尊敬語・謙譲語（＋参考列として合計。合計は除外対象）                   | 3（+1除外） |
| 文長   | 平均・中央値・90%点                                                            | 3           |
| 段落長 | 平均・中央値・90%点                                                            | 3           |

各項目の値は、LSM平均は媒体間LSM値そのもの、それ以外は「編集対象の値 − お手本の値」（文法語は100倍したポイント差、丁寧度は千形態素あたりの差、文長・段落長は字数差）。

## 強調規則

- LSM平均以外の各項目：`abs(編集対象 − お手本) > max(お手本 × 0.2, 群の最小差)`を満たすスコープを強調（`flaggedRowList`）とする。境界と等しい値は強調しない。浮動小数の誤差許容値は`1e-12`。
- 群の最小差（絶対下限）：文法語0.1ポイント、文末1ポイント、丁寧度1‰、文長5字、段落長5字。
- LSM平均のみ例外で、相対・絶対下限ではなくPennebaker(2011)のhigh synchrony目安である`0.85`未満を強調対象とする（`lsmSynchronyThreshold`）。
- 敬語合計（丁寧度・合計）は強調・件数集計から除外する（重複集計を避けるため）。

## 件数と分類

各スコープの強調件数は、上記27項目のうち強調に該当した列数。分類は次の閾値で決める（全体行は分類対象外。個別スコープのみに適用）。

| 分類                                 | 条件                                          |
| ------------------------------------ | --------------------------------------------- |
| `close`（近さを保てている章）        | 平均LSMが0.90以上 **かつ** 強調件数が7以下    |
| `priority`（優先章）                 | 平均LSMが0.88未満 **または** 強調件数が10以上 |
| `targeted`（項目を絞って確認する章） | 上記いずれにも該当しない                      |

分類はそのスコープ自身の値とお手本の値だけで決まり、他スコープの値が変わっても変化しない。

## 寸評の対象項目

スコープごとの寸評（`commentList[i]`）は、固定の優先順（数量詞→終助詞→段落長中央値→丁寧語→謙譲語→です・ます）のうち強調に該当した項目から先頭2件を選ぶ。数量詞はこの優先順の先頭に置かれる。この優先順は寸評専用で、分類・総括の対象指標選定には使わない。

## 分類と総括の対象指標

スコープごとの`assessmentList[i].targetList`、および総括文「優先章で`{modelLabel}`へ寄せる方向」の対象指標（最大2件）は、次の手順で選ぶ。

1. 文法語のうち数量詞を除いた強調項目を、その項目のカテゴリ別LSM昇順・列番号順に並べ替え、先頭2件を選ぶ。
2. 該当がない場合（強調項目はあるが文法語の強調がない場合）、フォールバックとして「LSM群を除く強調項目」を「その群の許容幅に対する差の絶対値が大きい順（`-abs(値)/limit`順）」に並べ替え、先頭2件を選ぶ。

数量詞はこの選定の対象から外し、「全体スコープの共有調整」で別枠として扱う。

## 移動方向の文言

移動方向の文言（`movement`）は数値の増減から機械的に生成する。意味の解釈や理由は含めない。

- 文長・段落長：差が正（編集対象がお手本より長い）なら「短くする」、負なら「長くする」。
- 文法語・文末：差が正なら「比率を下げる」、負なら「上げる」。
- 丁寧度：差が正なら「密度を下げる」、負なら「上げる」。

## 全体スコープの共有調整

強調列のうち、個別スコープすべてで揃って強調され、かつ全個別スコープの差の符号が同じ（全て正または全て負）である列を「全編に共通する調整」として抽出する。判定対象は個別スコープのみで、全体行（添字0）は含めない。抽出対象は集計対象（`counted`）の列すべてで、LSM平均も対象から除外されない（LSM平均は`counted: true`のため）。ただし平均LSMが全個別スコープで同時に強調（0.85未満）へ該当することは現状のデータにはなく、実際にLSM平均がここに現れることはない。本文の「全N区分に共通します」のNは個別スコープの件数。

## 総括文の生成

総括文（`summary`）の生成順は固定。`close`（1.）だけは該当なしでも定型文を出す。`priority`（2.）・`targeted`（4.）は該当なしなら見出しごと出力しない。3.（優先章で`{modelLabel}`へ寄せる方向）は`priority`が1件以上あり、かつ移動方向の文言が生成できたときだけ出力する。5.（全編に共通する調整）は該当があるときだけ出力する。見出し中の`{modelLabel}`はプレースホルダで、手元のファイルにはこの文字列のまま書き、表示名はmicroCMSの`series.modelLabel`で解決する。

1. 「`{modelLabel}`への近さを保てている章」：`close`分類のスコープを列挙。該当なしの場合は定型文。
2. 「調整を優先する章」：`priority`分類のスコープを列挙。該当なしなら出力しない。
3. 「優先章で`{modelLabel}`へ寄せる方向」：`priority`各スコープについて、対象指標選定と同じ手順で選んだ最大2項目の移動方向を、スコープごとに1文へまとめる。
4. 「項目を絞って確認する章」：`targeted`分類のスコープを列挙。該当なしなら出力しない。
5. 「全編に共通する調整」：上記「全体スコープの共有調整」の結果を1文にまとめる（該当があるときだけ出力）。

## overview_criteria.json

`overview-policy.md`のルール適用結果を保存するJSON。フィールド：

| フィールド              | 内容                                                                                                                                                                                                                                                                   |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `method`                | 強調規則の説明文（相対・絶対閾値とLSM平均の例外を1文で記述）                                                                                                                                                                                                           |
| `status`                | ルールが暫定であることの明示文                                                                                                                                                                                                                                         |
| `relativeLimit`         | 相対閾値（0.2）                                                                                                                                                                                                                                                        |
| `absoluteLimitList`     | 群ごとの絶対下限（キーは群名）                                                                                                                                                                                                                                         |
| `lsmSynchronyThreshold` | LSM平均の閾値（0.85）                                                                                                                                                                                                                                                  |
| `excluded`              | 集計除外項目の名称リスト（敬語合計）                                                                                                                                                                                                                                   |
| `policy`                | `POLICY`定数のスナップショット                                                                                                                                                                                                                                         |
| `sourceList`            | 参照した`comparison_data*.json`のファイル名とSHA-256のリスト                                                                                                                                                                                                           |
| `countDenominator`      | 集計対象項目数（27）                                                                                                                                                                                                                                                   |
| `labelList`             | スコープ名のリスト（全体＋個別スコープ、先頭が全体。個別スコープはid昇順で、表示名の代わりにプレースホルダー`{scopeList.label:N}`、Nはスコープid）                                                                                                                     |
| `countList`             | スコープごとの強調件数（`labelList`と同順）                                                                                                                                                                                                                            |
| `columnList`            | 28列分の判定情報。各要素は`group`・`item`・`unit`・`counted`（集計対象か）・`model`（お手本の基準値。LSM平均のみ`null`）・`limit`（許容幅または閾値。敬語合計の行は`null`）・`valueList`（全スコープ分の差分値配列）・`flaggedRowList`（強調に該当したスコープの添字） |
| `commentList`           | スコープごとの寸評（後述）                                                                                                                                                                                                                                             |
| `assessmentList`        | スコープごとの分類結果（後述）                                                                                                                                                                                                                                         |
| `summary`               | 総括文（見出しと本文のペアのリスト）                                                                                                                                                                                                                                   |

`commentList[i]`は`label`（スコープ名。`labelList`の個別スコープと同じプレースホルダー`{scopeList.label:N}`）・`lsm`（平均LSM）・`bulletList`（対象指標選定の結果を「〜が`{modelLabel}`より多い／少ない／長い／短い」で表した最大2文の配列）・`action`（移動方向をまとめた1文）・`text`（先頭に`平均LSM {値:.3f}。`を付け、続けて`bulletList`と`action`を連結した200字以内の寸評本文）を持つ。

手元のファイルでは、お手本媒体の表示名もプレースホルダー`{modelLabel}`で書く（`commentList`・`summary`の文中）。表示名はmicroCMSの`series`が持つので、画面は寸評・総括をmicroCMSの名前で再計算する。

`assessmentList[i]`は`row`（スコープの行番号。全体を除く1始まり）・`label`・`lsm`・`count`（強調件数）・`classification`（`close`/`priority`/`targeted`）・`targetList`（対象指標選定の結果。`columnList`の添字の配列、最大2件）を持つ。

## comparison_data*.json

`overview_criteria.json`の入力となる、スコープごとの生の比較データ。`comparison_data.json`が全体、`comparison_dataN.json`（Nはスコープid）が各スコープ。

| フィールド        | 内容                                                                                                                                                                                       |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `sourceList`      | 比較対象2件（お手本・編集対象）のプロファイルファイルの相対パス・SHA-256・`corpusSize`。全体スコープはさらに各`sourceFileList`（計測に使った文書ごとの`sourceRef`・`path`・SHA-256）を持つ |
| `comparisonScope` | 全体スコープ（`comparison_data.json`）のみ持つ、比較の前提を明示する固定の説明文字列                                                                                                       |
| `axisList`        | スコープ別の`comparison_dataN.json`のみ持つ。観点タブのペア棒グラフの最大値（`endings`・`politeness`・`sentence`・`paragraph`の4キー）                                                     |
| `lsm`             | `formula`（算出式の文字列）・`categoryList`（10カテゴリ分の`category`・`label`・`model`・`edited`・`lsm`）・`mean`（平均LSM）                                                              |
| `sentenceEnding`  | `unit`（`percent`）・`rowList`（7ラベル分の`[ラベル名, お手本の値, 編集対象の値]`のタプル配列）                                                                                            |
| `politeness`      | `unit`（`per 1000 morphemes`）・`rowList`（丁寧語・尊敬語・謙譲語・合計の同形式配列）                                                                                                      |
| `length`          | `unit`（`characters`）・`rowList`（`sentence`/`paragraph`それぞれに平均・中央値・90%点の同形式配列）                                                                                       |

各スコープの`comparison_dataN.json`はさらに`section`（スコープid）・`label`（スコープの表示名のプレースホルダー`{scopeList.label:N}`）を持つ。

## 分類境界・movement文言・スコープ独立性の検証

判定規則の実装は次を検証する。

- 分類境界：`close`はLSM 0.90かつ件数7以下でのみ成立し、件数8では`targeted`に落ちる。LSM 0.88ちょうど・件数9は`targeted`。LSM 0.879・件数5は`lsmBelow`（0.88未満）の条件で`priority`になる。LSM 0.95・件数10以上は`countAtLeast`（10以上）の条件で`priority`になる。
- `movement`の文言：文法語・文末は差が負で「上げる」、正で「下げる」。段落長は差が正（長い）で「短くする」。
- 他スコープの値を変えても、対象スコープの入力（値・お手本・閾値）が同じであれば、そのスコープの総括文の該当箇所は変化しない（スコープごとの分類・強調が他スコープから独立していることの検証）。

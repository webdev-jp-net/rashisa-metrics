# 画面構成と挙動

文体解析レポートのページ（`/<seriesKey>/`）の構成と、タブ切替・URLハッシュ同期・検索時自動展開・スクロールの挙動、ルート（`/`）のシリーズの一覧を定義する。見た目は[デザイン規約](../design-system.md)、画面の固定文言の正本は`src/app/_parts/model/build.ts`と各部品の`use*.ts`。

レポートのページは、そのシリーズの許可リストにあるGoogleアカウントでログインした閲覧者に表示する。許可リストが空のシリーズは、ログインしていない閲覧者にも表示する。それ以外の閲覧者にはログイン促し画面（後述）を表示する。

## ページ構造

上から次の3区画。ヒーローと解析導入は画面の高さいっぱいの区画で、レポート本体を含めた3つがスクロールの吸着位置になる。

| 区画         | id                | 内容                                                         |
| ------------ | ----------------- | ------------------------------------------------------------ |
| ヒーロー     | `#top`            | タイトル・リード文・導入文と、解析導入へのリンク             |
| 解析導入     | `#analysis-intro` | 導入文とレポート本体へのリンク、4つの観点の定義カード        |
| レポート本体 | `#report-view`    | スコープ切替ナビと、全スコープ（全体＋個別スコープ）のパネル |

### ヒーロー

タイトル・リード文はパスのシリーズの`siteTitle`・`siteLead`、導入文は同じシリーズの`description`（リンクだけを許可したリッチテキスト）をサニタイズして出す。`description`が空なら`src/lib/api/microcms.ts`の初期値を出す。

### 解析導入

導入文とレポート本体へのリンク、4つの観点（LSM・文末表現・敬語の密度・文・段落の長さ）の定義カードを並べる。定義カードの内容はデザイン規約の軸定義カード節を参照。観点の定義はここに1度だけ出し、各分析パネルでは繰り返さない。

## シリーズの一覧

ルート（`/`）の画面（`SeriesIndex`）。サービス名と何のサービスかの説明に続けて、その人が閲覧できるシリーズのレポートへのリンクの一覧を小見出し付きで出し、最後に注釈とログインまたはログアウトのボタン（secondary、[デザイン規約のボタン](../design-system.md#ボタン)）を出す。

一覧に出るのは、未ログインなら許可リストが空のシリーズ、ログイン済みならそれに加えて許可リストにあるシリーズ。1件も無ければ小見出しごと出さない。シリーズ名がシリーズどうしで同じでもそのまま並べる。ログインした後はルートへ戻る。

## ログイン促し画面

許可されたGoogleアカウントでログインしていない場合、レポートのページの代わりにこの画面（`LoginPrompt`）を表示する（[NextAuth認証仕様](../backend/next-auth.md)参照）。サイトタイトル・リード文・状態ごとのメッセージ・ボタン（secondary）だけを出し、スコープナビ等は持たない。

| 状態         | 表示条件                         | メッセージ                                         | ボタン         |
| ------------ | -------------------------------- | -------------------------------------------------- | -------------- |
| `signedOut`  | 未ログイン                       | 限定公開であり、権限のあるアカウントで閲覧できる   | ログインする   |
| `notAllowed` | ログイン済みだが許可リストに無い | 上に加えて、閲覧権限がないアカウントでログイン中だ | ログアウトする |

## スコープ一覧とid

全体スコープ（`total`）と個別スコープ。個別スコープの件数・id・表示名はパスのシリーズの`scopeList`（microCMSの`series`）から読み、件数は固定しない。パネルのidは`report-{key}`、対応するタブのidは`tab-report-{key}`（`key`は`total`または`scopeId`）。

## スコープパネルの内容

各スコープパネルは、提案パネルと分析パネルを区切り線で分けて並べる。`revisionStatus`が`complete`でないスコープは提案パネルを空にする。

### 全体スコープ

提案パネルに、上から次を出す。

1. **概要リード文**：お手本媒体・編集対象媒体の表示名（シリーズの`modelLabel`・`editedLabel`）を使った分析の説明、全体LSMの値としきい値（0.85）に応じた定性文、LSMが最も低いスコープと最も高いスコープ。媒体名はコードに直書きしない
2. **箇条書きの提案**：全体行で基準超過した項目を、`{観点} - {項目名}を{増やす/減らす/長くする/短くする}調整`の形で並べる。方向は差の符号で決まる（文長・段落長は編集対象のほうが長ければ短くする、それ以外は多ければ減らす）。LSM平均だけは全体の類似度を上げる調整として出す
3. **比較テーブル**：後述

### 個別スコープ

提案パネルに、上から次を出す。

1. 基準超過の指標があるかどうかに応じた1文
2. 平均LSMの提案前後の値
3. 再測定テーブル（デザイン規約の再測定テーブル節を参照）
4. diffボックス（後述）

### 比較テーブル

全体行と個別スコープの行を並べ、スコープ名・差のある指標の数（27指標中）・文字数と、各指標の列を出す。基準を超えたセルは強調する（基準は[判定規則](../../analysis/overview-policy.md)）。

- スコープ名はボタンで、押すとスコープ切替ナビの同じスコープのタブを押したのと同じになる。テーブル自身は切替の状態を持たない
- フィルターボタンで、表示する指標の列を切り替える（主要項目〈既定〉・4つの観点ごと・全項目）
- 各セルは、その値の根拠（お手本の値と差の許容幅など）を補足として持つ

## 分析パネル

見出しの下に観点タブと4つのタブパネルを置く。観点は`lsm`・`endings`・`politeness`・`length`で、パネルのidは`report-{scope}-{axis}`。

- **LSM**：カテゴリ別LSM図と所見テキスト
- **文末表現**：文末表現の割合のペア棒グラフと所見テキスト
- **敬語の密度**：形態素1,000あたりの敬語密度のペア棒グラフと所見テキスト
- **文・段落の長さ**：一文と段落の長さの分布要約のペア棒グラフと所見テキスト

所見テキストは、そのシリーズの総評（microCMSの`report.findingList`）の該当スコープ・観点をそのまま出す。原稿の再計測では更新されない。

## タブのARIA・キーボード操作

スコープタブと観点タブは同じ実装に従う。

- タブ列は`tablist`、各タブは`tab`、パネルは`tabpanel`のロールを持ち、タブとパネルを`aria-controls`・`aria-labelledby`で結ぶ。選択中のタブだけがフォーカス順に入る
- 左右の矢印キーで同じタブ列の前後のタブへ移り、そのタブを選択する（端では反対側へ回る）。クリックでも選択する
- 非選択のパネルは、ページ内検索で見つけられる形で隠す（後述）

## URLハッシュ同期

スコープタブの選択だけをURLハッシュと同期する。観点タブとフィルターボタンは同期しない。

- スコープタブを選ぶと、ハッシュを選んだパネルのidにして履歴に積む
- ブラウザの戻る・進むと、ページを読み込んだときにも、ハッシュに一致するタブを選ぶ。一致しなければ全体スコープを開く
- ヒーローと解析導入へのリンクは通常のアンカーリンクで、タブの仕組みとは関係なく履歴に入る

## ページ内検索との連動

非選択のタブパネルは、表示はしないが中の文字をページ内検索の対象に残す。検索でパネル内の文字に一致すると、そのパネルのタブを選んで開く（このときはハッシュを更新しない）。

## スティッキーなスコープ切替ナビ

レポート本体のスコープ切替ナビは、スクロールしても画面上端に留まる。先頭のサイトタイトルはヒーローへのリンクで、ページ先頭へ戻る導線を兼ねる。見た目は[デザイン規約のスティッキーなスコープ切替ナビ](../design-system.md#スティッキーなスコープ切替ナビ)を参照。

## スムーズスクロール

アンカーリンクでの移動はスムーズスクロールにする。比較テーブルのスコープ名ボタンはタブを開くだけで、スクロールしない。

## diffボックスの折りたたみ

変更のない行が前後の文脈（3行）を超えて続く区間は、初めは折りたたんで出す。見た目は[デザイン規約の折りたたみ制御](../design-system.md#折りたたみ制御)を参照。

- 折りたたみを押すと、隠れている行を先頭から10行ずつ表示し、残りが無くなると折りたたみ自体を消す
- ヘッダーのボタンで、すべての折りたたみを展開する・初めの状態に戻すを切り替える

## スクロールに応じた挙動

- スコープ切替ナビは、画面上端に貼り付いた状態で見た目を切り替える
- グラフは画面に入ったときに一度だけ、バーが伸びるアニメーションを始める
- ヒーローと解析導入は、画面から出ていくにつれて薄くぼかす。スクロール駆動アニメーションに対応しないブラウザでは、スクリプトで同じ効果を出す

## その他

- Google Fontsが読み込めない場合のフォールバックは[デザイン規約の書体](../design-system.md#書体)を参照
- ファビコンはページに埋め込み、外部ファイルを参照しない
- 画面幅による構成の切り替えはない

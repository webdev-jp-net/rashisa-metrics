# microCMS連携仕様

## 概要

画面が表示に使う材料（シリーズの表示名・スコープごとの比較データ・変更案・総評）はmicroCMSに置き、Next.js App RouterのServer Component（`src/app/page.tsx`・`src/app/[seriesKey]/page.tsx`）がリクエストのたびに取得・描画する。原稿・計測結果そのものはmicroCMSに置かず、表示用に組み立てた本文・数値だけを送る。取得・型定義は`src/lib/api/microcms.ts`に集約する。

APIは`series`（リスト形式。お手本と編集対象の組＝シリーズを1件ずつ持つ）・`report`（リスト形式。シリーズごとに全体スコープ＋`series.scopeList[].scopeId`の数だけ）の2本。フィールドはすべて型付きで、JSON文字列は使わない。繰り返しフィールドの列にあるカスタムフィールドID（`scope`等）は`src/lib/api/microcms.ts`の`fieldId`と一致させる。カスタムフィールドはAPIごとに持つので、`scope`は`series`のカスタムフィールドとして作る。

## APIの作成

管理画面で`series`（リスト形式）・`report`（リスト形式）の2APIを、下記のフィールド一覧表のとおりに作成する。

## 環境変数

- `MICROCMS_SERVICE_DOMAIN`：サービスドメイン
- `MICROCMS_API_KEY`：APIキー（サーバー側だけで使う。`push`は`report`の新規作成に`POST`〈コンテンツIDは自動発行〉、更新に`PATCH`、スコープと原稿ファイルの対応から消えたスコープの`report`の削除に`DELETE`を使う（`series`は読むだけで書かない）。microCMSの「コンテンツAPI」権限にはHTTPメソッド単位で絞る項目が無く、APIキーは既定で読み書き両方できる）

## コンテンツモデル（series）

リスト形式。1件が1シリーズ。画面に出す表示名（スコープ・媒体・タイトルとリード文）とヒーローの導入文の正本で、手元の設定は表示名を持たない。新しいシリーズはエージェントが`data/index.json`と`<editedSource>/index.json`、ユーザーから聞いた表示名・許可リストをもとに登録し、その後の直しはユーザーが管理画面で書く。送信コマンド（`push`）は`series`を作らず、書き換えもしない。

| フィールドID  | 型                  | 必須 | 内容                                                                                                                                                                                                                                                                                                                                                   | 書き手                 |
| ------------- | ------------------- | :--: | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------- |
| `seriesKey`   | テキスト            |  ○   | シリーズの識別子。英数字・`-`・`_`だけで書く（画面はそれ以外の文字を含むパスを404にする）。`data/index.json`の`seriesKey`と同じ値で、画面のパス（`/<seriesKey>/`）と、送信コマンドが送り先を引くのに使う。重複を許可しない設定にする（ONでも重複が登録できる[既知の不具合](https://help.microcms.io/ja/knowledge/unique-field-duplicate-issue)がある） | 管理画面／エージェント |
| `siteTitle`   | テキスト            |  ○   | 画面のタイトル。ルートのシリーズ一覧ではシリーズ名に使う                                                                                                                                                                                                                                                                                               | 管理画面／エージェント |
| `siteLead`    | テキスト            |  ○   | 画面のリード文                                                                                                                                                                                                                                                                                                                                         | 管理画面／エージェント |
| `description` | リッチエディタ      |  ー  | 画面のヒーローの導入文。リンクだけを許可する。フィールドの初期値は`src/lib/api/microcms.ts`の`DEFAULT_DESCRIPTION`と同じ文。表示は[画面構成と挙動](./frontend/screen.md#ヒーロー)                                                                                                                                                                      | 管理画面／エージェント |
| `modelLabel`  | テキスト            |  ○   | お手本媒体の表示名                                                                                                                                                                                                                                                                                                                                     | 管理画面／エージェント |
| `editedLabel` | テキスト            |  ○   | 編集対象媒体の表示名                                                                                                                                                                                                                                                                                                                                   | 管理画面／エージェント |
| `scopeList`   | 繰り返し（`scope`） |  ○   | スコープ一覧。各行は`scopeId`（数字。`<editedSource>/index.json`の`id`をもとに登録する。`id`はmicroCMSの予約語のため使えない）・`label`（テキスト、スコープの表示名）を持つ                                                                                                                                                                            | 管理画面／エージェント |
| `allowList`   | テキストエリア      |  ー  | このシリーズの閲覧許可リスト。1行1件。`@`を含む行はメールアドレスの完全一致、含まない行はドメイン一致として判定する（前後の空白・大文字小文字は無視）。1件も登録していなければmicroCMSはこのフィールドを返さず、そのシリーズのレポートはログインせずに閲覧できる                                                                                       | 管理画面／エージェント |

## コンテンツモデル（report）

リスト形式。コンテンツIDは自動発行で、1件は`series`と`scope`の組で決まる（`scope`はシリーズをまたいで重複するのでユニーク設定はしない）。全体スコープは`beforeText`以降のフィールドを持たない。個別スコープのうち変更案が未完了（`proposalReady`が`false`）のものは、`beforeText`以降のフィールドに空値（空文字列・空配列・`0`）が入る（原稿の差し替えで`complete`から外れたときに、前回送信分の本文・理由行を消すため）。

| フィールドID          | 型                          | 必須 | 内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | 書き手                      |
| --------------------- | --------------------------- | :--: | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------- |
| `series`              | コンテンツ参照（`series`）  |  ○   | 属するシリーズ。画面はパスのシリーズのidで`report`を絞り込む                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | push                        |
| `scope`               | テキスト                    |  ○   | `total`（全体スコープ）または`series.scopeList[].scopeId`の値（`<editedSource>/index.json`の`id`）                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | push                        |
| `chars`               | 数字                        |  ○   | 編集対象媒体の文字数                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | push                        |
| `lsmMean`             | 数字                        |  ○   | LSM（Language Style Matching）の平均値                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | push                        |
| `lsmCategoryList`     | 繰り返し（`lsmCategory`）   |  ○   | LSMのカテゴリ別内訳。各行は`label`（テキスト）・`model`（数字、お手本媒体の値）・`edited`（数字、編集対象媒体の値）・`lsm`（数字、そのカテゴリのLSM値）を持つ                                                                                                                                                                                                                                                                                                                                                                                                                  | push                        |
| `sentenceEndingList`  | 繰り返し（`comparisonRow`） |  ○   | 文末表現の比較行。各行は`label`（テキスト）・`model`（数字）・`edited`（数字）を持つ                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | push                        |
| `politeness`          | 繰り返し（`comparisonRow`） |  ○   | 敬語の密度の比較行（フィールド構成は`sentenceEndingList`と同じ）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | push                        |
| `sentenceLengthList`  | 繰り返し（`comparisonRow`） |  ○   | 一文の長さの比較行（フィールド構成は`sentenceEndingList`と同じ）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | push                        |
| `paragraphLengthList` | 繰り返し（`comparisonRow`） |  ○   | 段落の長さの比較行（フィールド構成は`sentenceEndingList`と同じ）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | push                        |
| `findingList`         | 繰り返し（`finding`）       |  ー  | 総評4観点。各行は`axis`（セレクト、選択肢`lsm`／`endings`／`politeness`／`length`）・`heading`（テキスト、見出し）・`paragraphList`（テキストエリア、1段落1行）・`evidenceItemList`（テキストエリア、根拠にした指標名を1行1件）・`evidenceExemplarList`（テキストエリア、根拠にした実例集IDを1行1件）を持つ。`evidenceItemList`・`evidenceExemplarList`は画面が読まない、執筆時の根拠記録用の値。`push`は書かないため必須にしない（必須にすると初回`push`のコンテンツ作成が通らない）。`push`でコンテンツを作った後、`import-findings`で書き込むまでは画面は総評の欠けで止まる | 管理画面／`import-findings` |
| `proposalReady`       | 真偽値                      |  ○   | 変更案が完成しているか（`revisionStatus === 'complete'`）。全体スコープは常に`false`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | push                        |
| `beforeText`          | テキストエリア              |  ー  | 変更前のスコープ本文（前処理後、実名等をマスク済み）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | push                        |
| `afterText`           | テキストエリア              |  ー  | 変更案を当てた本文（同上）                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | push                        |
| `reasonList`          | 繰り返し（`reason`）        |  ー  | 変更案の理由行。各行は`line`（数字、変更前本文の何行目か・0始まり）・`title`（テキスト、見出し）・`reason`（テキスト、変更理由）・`tradeoff`（テキスト、変更で薄れる・強まる意味や語調）を持つ                                                                                                                                                                                                                                                                                                                                                                                 | push                        |
| `metricList`          | 繰り返し（`metric`）        |  ー  | 再測定の全指標。各行は`genre`（テキスト、観点名。平均LSMの行だけ空）・`item`（テキスト、指標名）・`unit`（テキスト、単位。平均LSMの行だけ空）・`before`（数字）・`after`（数字）・`model`（数字、お手本媒体の値）・`target`（真偽値、基準超過の対象か）を持つ。`genre`・`unit`は値を持たない行があるため必須にしない。画面は`target`が`true`かつ値が動いた行だけを表にする                                                                                                                                                                                                     | push                        |
| `lsmBefore`           | 数字                        |  ー  | 平均LSMの変更前の値                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | push                        |
| `lsmAfter`            | 数字                        |  ー  | 平均LSMの変更後の値                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | push                        |

## 送信コマンド（`scripts/cms.ts`）

送る内容の組み立てと書き込みは`scripts/cms-content.ts`が行う。

| コマンド                 | 内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `push`                   | 引数`--series`の`seriesKey`で`series`を探す（`series`は書かず、microCMSに無ければ何も書かずに止める）。そのシリーズの`report`（`findingList`を除く全フィールド）は`scope`が一致するコンテンツを`PATCH`で更新し、無ければ`series`を付けて`POST`で作り、`<editedSource>/index.json`に無いスコープのコンテンツは`DELETE`で消す。送信前に各スコープの原文・改稿のSHA-256と変更案の`before`が本文と一致するかを検証し、1件でも不一致なら1件も送信しない。原稿の差し替えで`complete`から外れたスコープは、変更案フィールドを空値で上書きして前回送信分を消す |
| `push --check`           | 送信せず、いまmicroCMSにある内容と、手元から組み立てた内容の差分（値が違うフィールド名の一覧）だけを出す。`series`が無ければ`push`と同じく止める。あるコンテンツが無ければそのコンテンツを`missing`として、`<editedSource>/index.json`に無いスコープのコンテンツを`stale`として列挙する                                                                                                                                                                                                                                                                |
| `import-findings <path>` | `finding_texts.json`と同じ形のファイルを読み、引数`--series`のシリーズにある`report`の`findingList`フィールドだけを書き込む（他のフィールドは触らない）。初回の総評移行と、まとめて書き直したときに使う。スコープキーが`all`・数字のどちらでもない、4観点のいずれかで見出し・段落が欠けている、シリーズが無い、またはそのスコープの`report`が無ければ、書き込む前に止める                                                                                                                                                                              |

実行時のエラー（上限超過・認証失敗等）はmicroCMSのAPIの応答をそのまま出して止める。環境変数は`bun --env-file=.env.local`で読む。
